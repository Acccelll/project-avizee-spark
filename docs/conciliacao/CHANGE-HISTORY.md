# Change History — Conciliação Financeira

Histórico consolidado e cronológico de alterações do módulo. Cada linha aponta para o registro completo no Journal quando aplicável.

## Categorias

- **FT** Feature
- **HF** Hotfix
- **RF** Refatoração
- **BF** Correção (bug fix)
- **IM** Melhoria
- **SE** Segurança
- **PF** Performance
- **DO** Documentação
- **AR** Ajuste arquitetural
- **RQ** Mudança de requisito

## Formato de Registro

```text
YYYY-MM-DD | CAT-ID | Título | Autor | Sprint/Release | Impacto | Link (relative path)
```

## Regras

- Uma linha por alteração relevante.
- Ordem cronológica decrescente.
- CAT-ID único e sequencial por categoria (ex.: FT-0001, HF-0007).
- Impacto: Baixo / Médio / Alto / Crítico.
- Link aponta para o arquivo do Journal com detalhes completos.
- Alterações de documentação também entram aqui (categoria DO).

## Auditoria

- Revisão semanal pelo Tech Lead.
- Revisão trimestral cruzada com `IMPLEMENTATION-JOURNAL.md`.
- Divergências viram itens no `READINESS-AUDIT.md`.
